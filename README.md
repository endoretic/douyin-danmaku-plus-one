# 抖音弹幕 +1

在 Chrome / Edge 的抖音网页中，点击视频画面上的漂浮弹幕，核对原文后选择 **+1 发送**。

## 安装

1. 下载 Release 中的 ZIP 并解压。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启「开发者模式」，点击「加载已解压的扩展程序」，选择解压后的 **extension** 文件夹。
4. 刷新抖音直播间，登录账号，并开启播放器弹幕。

页面左下角出现 **「+1 已就绪」** 后，即可点击漂浮弹幕，再点击卡片里的「+1 发送」。按 Esc 或点击空白处取消。

更新时，用新版文件覆盖原来的扩展目录，在扩展管理页点击「重新加载」，然后刷新直播间。扩展卡片及工具栏弹窗会显示版本号；不要只重载旧版解压目录。

## 使用说明

- 输入框已有草稿时不会覆盖；每次只提交一条，不自动重试。
- 发送结果、登录要求及发言限制以抖音页面提示为准。
- 工具栏图标中可停用功能、查看当前页面连接状态。
- 主要适配直播间。普通短视频、图片表情及网站改版后的页面可能无法完整识别，请先核对预览内容。

遇到点击无反应，先确认扩展版本及网站访问权限，然后重新加载扩展并刷新直播间。左下角没有任何「+1」状态，说明本页尚未运行新版扩展。

扩展仅在抖音网页运行，没有额外后台服务，发送通过抖音原有聊天框完成；不读取 Cookie，不需要提供账号密码。兼容绘制会使用网页主线程，弹幕密集时可能增加页面负担。
